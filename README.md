# STACK

한국어 테트리스 웹 게임. 별도 패키지 설치 없이 동작합니다.

## 실행

```sh
cd /workspace/gpt
npm start
```

포트 3000에서 정적 사이트를 제공합니다. `index.html`을 여는 대신 HTTP 서버를 사용하세요(ES 모듈).

## 검증

```sh
npm test
```

방향키 이동·회전, Space 즉시 낙하, C 보관, P 일시정지, R 재시작. 모바일은 화면 아래 버튼을 사용합니다. 7종 가방 방식, 다음 블록 3개, 고스트 블록, 최고 점수 로컬 저장을 지원합니다. 외부 글꼴이 차단되면 시스템 글꼴로 표시됩니다.
